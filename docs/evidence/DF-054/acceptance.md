## 页面审校结果

| 页面 | 审校与优化结果 |
| --- | --- |
| 运行概览 | 修正“使用中设备”为预约中与忙碌设备之和；增加故障设备；五项核心指标使用自适应网格；入口名称统一为“运行概览”。 |
| 宿主机 | 主表仅保留身份、Agent/调度、关键容量、心跳和操作；明确 Agent 在线不等于设备可用；内部地址、能力上报和完整规格进入管理员详情。 |
| 设备池 | 主表直接显示目标、可用、使用中、恢复中、故障和缺口；故障设备不计入可服务容量；扩缩容配置继续复用统一容量目标。 |
| 设备 | 默认突出可用设备，故障和历史记录分开；系统版本、设备池、可用性和直接操作保持可见；完整编号、能力、运行规格、ADB/Appium Endpoint 进入管理员详情。 |
| 预约 | 主表显示剩余租期、等待分配和中文失败原因；只允许从 active Pool 创建预约；技术时间点和完整编号进入详情。 |
| 健康事件 | 默认优先选择故障设备并支持 `device_id` 深链；主表显示事件、来源和中文原因；原始 payload 进入详情。 |
| 操作审计 | 入口名称明确为“操作审计”；主表保留时间、操作者、操作对象和原因；原始 summary 与完整编号进入详情。 |
| 登录与全局 | 登录文案统一；所有资源页增加用途说明、最近更新时间、自动/手动刷新、可重试错误和明确空状态；移动端折叠菜单不泄漏文字。 |
