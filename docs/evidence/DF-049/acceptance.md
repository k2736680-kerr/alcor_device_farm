# DF-049 统一设备农场控制台功能与中文文案审校验收证据

验收日期：2026-08-20

## 结论

通过。控制台已经从 Android 单平台口径统一为 Android+iOS 设备农场。iOS 设备池目标数量可编辑，Android 与 iOS 使用同一套目标、扩容模板和安全缩容表达；Android 专属镜像、ADB、STF 及 iOS 专属 CoreSimulator、运行时、机型、受控会话只在对应位置出现。

## 逐页审校结果

- 导航与登录：产品名称统一为“Alcor 设备农场”，明确同时管理 Android 与 iOS；登录字段统一为“用户账号”。
- 运行概览：宿主机说明覆盖 Linux 与 macOS；“当前任务/清理中”改为“设备处理状态/回收或停止中”。
- 宿主机：平台、系统、宿主机类型、动态容量、iOS 运行环境和自动化就绪状态使用平台化名称；排空说明明确已有预约不会中断。
- Android 镜像：导航和页面明确该能力只属于 Android，不再伪装为跨平台镜像功能。
- 设备池：Android 与 iOS 的目标设备数都可编辑；默认租期和最大租期窗口显示为中文时长；扩容模板、目标差额和宿主机容量不足使用真实数据与中文说明。
- 设备：平台、型号、系统版本、运行方式、维护方式和自动化接入按平台显示；Android 创建向导只允许选择 Android 池；iOS 创建只允许选择 Mac、iOS 运行时、兼容 iPhone 机型和 iOS 池。
- 预约：选择池后自动采用该池默认租期；“最大租期”明确为可续租的滑动窗口；释放说明明确不会自动清空设备数据。
- 健康事件与审计：字段名、动作、状态和详情使用中文；嵌套详情不再直接展示原始 JSON。
- 远控：Android 与 iOS 提示分别说明 STF 或受控 iOS 画面；关闭、挂断、超时和回收语义统一为预约状态，不再误写为清空设备。
- 所有成功或失败提示统一显示“请求编号”；上游英文错误不会直接作为用户提示显示，仍保留错误代码和请求编号用于追踪。

## 真实环境边界

本次只修改现有控制台展示、表单筛选和用户提示，没有改动已验收的宿主机、Provider、Scheduler、Reservation 或远控协议。Android 与 iOS 真实创建、预约、远控和自动伸缩能力继续使用 DF-047、DF-048 已保存的真实环境证据。`http://127.0.0.1:18888/` 当前为 Alcor 平台外壳而非独立 Device Farm 登录页，因此没有把独立控制台登录 E2E 错误地用于该地址，也没有为了本任务切换或替换现有后台。
